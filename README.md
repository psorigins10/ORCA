# 🐋 ORCA
### Offline Research & Coordinate Analysis

**A C++ research project exploring game entities, player positions, memory structures, and 3D-to-2D visualization concepts using Counter-Strike 2 research data.**

---

## 1. About the Project

ORCA is an educational C++ research project focused on understanding how modern multiplayer games represent player entities, positions, and game-state information.

The project's initial research objective is to develop an ESP-style player-position visualization system using authorized, offline, or simulated data.

The project aims to explore concepts commonly associated with game development, computer memory, reverse engineering, and graphics programming.

ORCA is intended for educational research and software development. It is not intended to provide an unfair competitive advantage in online multiplayer environments.

## 2. Primary Objectives

The initial objectives of ORCA are:

- Understand game entity structures and relationships.
- Study player-position data and 3D coordinate systems.
- Learn C++ memory management and data structures.
- Understand entity properties such as health, team, and position.
- Study world-to-screen coordinate transformations.
- Develop an ESP-style visualization prototype.
- Explore how game security and anti-cheat technologies protect multiplayer environments.

## 3. Initial Project Goal

**Phase 1: Offline Player Position Visualization**

The first prototype will demonstrate how player positions can be represented visually.

Planned visualization features:

- Player bounding boxes.
- Player position indicators.
- Distance information.
- Team identification.
- Health indicators.
- Basic 2D and 3D coordinate visualization.

All initial player information must originate from synthetic data, authorized offline replay/demo data, or an explicitly authorized test environment.

The visualization must not reveal hidden information to gain an advantage in live multiplayer matches.

## 4. Project Boundaries & Acceptable Usage

ORCA follows a strict research-only usage policy.

### Permitted Activities

- Studying C++ programming and memory management.
- Experimenting with synthetic game entities.
- Analyzing authorized offline demo/replay data.
- Developing visualization tools for offline research.
- Learning game-engine architecture and coordinate mathematics.
- Studying anti-cheat architecture from a defensive and educational perspective.
- Testing in self-created environments where the researcher controls the data and environment.

### Prohibited Activities

ORCA must not be developed, modified, distributed, or used for:

- Gaining an unfair advantage in public or competitive CS2 matches.
- Revealing hidden enemy positions during live multiplayer gameplay.
- Reading protected live game memory to obtain hidden competitive information.
- Injecting unauthorized code or DLLs into CS2.
- Bypassing, disabling, or interfering with VAC or Trusted Mode.
- Evading anti-cheat detection.
- Manipulating matchmaking or gameplay.
- Automating competitive gameplay.
- Distributing modified versions intended for cheating.
